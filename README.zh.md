# あと何时间（ato-jikan）

[日本語](README.md) ・ [English](README.en.md)

给在日本打工的学生用：按 **2026年（令和8年）规则**倒推**今年还能打多少小时工而不超过扶养线（年收之壁）**。同时计算留学生的每周28小时上限，并生成可分享的结果图（1080×1350）。

**▶ 在线使用：** https://jasonin2099.github.io/ato-jikan/

## 功能
- 输入时薪、今年已领总额和剩余发薪次数，算出“还能打几小时”
- 列出 136 / 150 / 159 / 178 / 197万日元 各道线，每条都附官方出处
- 按当前每周工时预估年末收入，以及父母扣除额的变化
- 留学生模式：上课期间每周28小时，长假每周40小时
- 全部计算在本机完成，不上传任何数据

## 规则与出处
所有数字都在 [`rules/2026.json`](rules/2026.json)。每一项都注明官方出处和年度：国税厅 No.1177 / 1410 / 1199 / 1180、令和8年度税制改正、日本年金机构、出入国在留管理厅。

## 免责声明
- **不计算住民税**：住民税的非课税线因市町村而异。
- **长假上限按保守的每周40小时计算**（每天8小时，依据劳动基准法第32条）。
- 只适用于工资收入。税的门槛看1–12月实际**支付**的金额；健康保险扶养看**未来一年的收入预估**，可能包含交通费。
- 结果仅供参考，具体请向雇主、父母的健康保险、税务署或入管确认。作者不承担任何责任。

## 开发
运行 `npm test`（需要 Node 18+）。`calc.js` 是纯计算模块，浏览器和 Node 都能用。明年新增 `rules/2027.json` 即可。发现规则错误，欢迎附上出处提 Issue 或 PR。

# 还能打几小时（ato-jikan）

[日本語](README.md) ・ [English](README.en.md) ・ **中文**

给在日本打工的学生（尤其是留学生）用的小工具：按 **2026年（令和8年）的规则**，倒推**今年还能打多少小时工，才不会超过「扶養」的线**。留学生的每周28小时上限也一起算，最后还能生成一张结果图，方便分享。

**▶ 在线使用：** https://jasonin2099.github.io/ato-jikan/ （页面右上角可切换 日本語 / 中文 / English）

![三种语言的界面](docs/hero.png)

## 先弄懂两个词
- **扶養（ふよう）**：被父母“扶养”。你的收入不超过一定金额，父母交税时可以少交一些（扶養控除），你也能继续挂在父母的健康保险下，不用自己交国民健康保险和年金。超过了，这些就没了。
- **資格外活動（しかくがいかつどう）**：留学签证本身是不能打工的，拿到「資格外活動許可」以后才可以。上课期间每周最多28小时，学校规定的长假期间每天最多8小时。

## 能做什么
- 输入时薪、今年已领的工资总额、还剩几次发薪，算出“还能打几小时”，以及每周、每月大概多少小时
- 列出 136 / 150 / 159 / 178 / 197万日元 这几道线，每一条都附官方出处
- 填上现在每周打几小时，可以看到年底大概会到多少，以及父母的控除会怎么变
- 留学生模式：上课期间每周28小时，长假每周40小时
- 生成 1600×2000 的结果图（发到 X 或朋友圈也看得清）
- 日语 / 中文 / 英语，跟随浏览器语言，也会记住你上次选的；深色模式跟随系统
- 所有计算都在你自己的设备上完成，不上传任何数据
- 打开过一次后离线也能用，可以添加到手机主屏幕

## 这几道线是怎么来的
数字全部在 [`rules/2026.json`](rules/2026.json)，每一项都写了官方出处和年度。

| 线 | 含义 | 出处 |
|---|---|---|
| 136万日元 | 74万（給与所得控除）＋62万（扶养亲属的所得要求） | 国税厅 No.1410 / 令和8年度税制改正 |
| 不到150万日元 | 19〜22岁可以留在父母健康保险里的上限（其他年龄是不到130万） | 日本年金机构 |
| 159万日元 | 特定親族特別控除开始从63万往下减 | 国税厅 No.1177 |
| 178万日元 | 74万＋基础控除104万：你自己开始交所得税 | 国税厅 No.1199 |
| 197万日元 | 特定親族特別控除降为零 | 国税厅 No.1177 |
| 每周28小时 | 留学生的資格外活動 | 出入国在留管理厅 |

## 注意
- **不计算住民税**：住民税的免税线各市町村不一样。
- **长假上限按保守的每周40小时算**（每天8小时，依据劳动基准法第32条）。
- 只适用于工资收入。税的线看1〜12月实际**发放**的金额；健康保险的扶養看**今后一年的收入预估**，有时也算交通费。
- 结果仅供参考，具体请向打工单位、父母的健康保险、税务署或入管确认。作者不对使用结果承担责任。

## 开发
```
npm test                 # node --test（Node 18+）
python3 -m http.server   # http://localhost:8000
```
- `calc.js`：纯计算模块，不依赖 DOM，浏览器和 Node 都能用
- `i18n.js`：日 / 中 / 英文案，缺的词自动用日语
- `rules/2026.json`：每年一份规则，明年加一个 `rules/2027.json` 就行
- `fonts/`：从 Noto Sans CJK 截出的子集字体，改了文案后运行 `python3 tools/subset-fonts.py` 重新生成

发现规则写错了，欢迎附上出处提 Issue 或 PR。
